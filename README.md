# ICONSIAM Food Picker

เว็บช่วยตัดสินใจเลือกร้านอาหารใน **ICONSIAM** และ **ICS** — ค้นหา กรองตามสถานที่/ชั้น/หมวดหมู่ เลือกร้านที่สนใจ แล้วให้วงล้อช่วยสุ่มมื้อถัดไป

## Demo

[เปิด ICONSIAM Food Picker](https://thanakritdacontact-tech.github.io/iconsiam-food-picker/)

## ฟีเจอร์

- รวมร้านอาหารจาก ICONSIAM และ ICS ไว้ในหน้าเดียว
- ค้นหาชื่อร้านและกรองตามสถานที่ ชั้น หรือประเภทอาหาร
- สุ่มร้านจากผลลัพธ์ที่กำลังแสดง
- เลือกตัวเต็ง 2–5 ร้านแล้วตัดสินด้วยวงล้อ
- แสดงภาพหน้าร้านจาก Google Maps หรือแหล่งข้อมูลที่ตรวจสอบแล้ว
- รองรับเดสก์ท็อป แท็บเล็ต และมือถือ
- รองรับคีย์บอร์ด สถานะ focus และ `prefers-reduced-motion`

## โครงสร้างโปรเจกต์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าเว็บ สไตล์ รายชื่อร้านหลัก และระบบค้นหา/สุ่มร้าน |
| `restaurant-updates.js` | ข้อมูลแก้ไขล่าสุด เช่น ลิงก์ รูป ชื่อ ชั้น และร้านที่นำออก |
| `missing-restaurant-images.csv` | ตารางตรวจสอบ Google Maps และสถานะร้านสำหรับดูแลข้อมูล |

โปรเจกต์นี้เป็น static site ไม่มีขั้นตอน build และไม่ต้องติดตั้ง dependencies

## รันในเครื่อง

เปิดผ่าน local web server เพื่อให้พฤติกรรมเหมือนตอน deploy:

```bash
python3 -m http.server 4173
```

จากนั้นเปิด [http://localhost:4173](http://localhost:4173)

## การดูแลข้อมูลร้าน

1. ตรวจชื่อร้านพร้อมคำว่า `ICONSIAM` หรือ `ICS` บน Google Maps
2. ถ้าพบหลายผลลัพธ์ ให้เลือกสาขาที่ตรงสถานที่และมีข้อมูลการใช้งานมากที่สุด
3. ถ้าไม่พบ Google Maps ให้ตรวจเว็บไซต์หรือ social media ของแบรนด์เพิ่มเติม
4. ถ้ายืนยันว่าไม่มีสาขาแล้ว ให้ระบุสถานะใน CSV และเพิ่ม key แบบ `สถานที่|ชื่อร้าน` ใน `closed`
5. เก็บลิงก์อ้างอิง รูป ชื่อที่แก้ไข และชั้นไว้ใน `restaurant-updates.js`
6. ทดสอบลิงก์ รูป ตัวกรอง และวงล้อทั้งบนเดสก์ท็อปและมือถือก่อน push

ข้อมูลหน้าร้านมีโอกาสเปลี่ยนแปลง ควรตรวจซ้ำกับ [ICONSIAM Dining](https://www.iconsiam.com/th/dining), [ICS Directory](https://ics.iconsiam.com/en/directory) และ Google Maps เป็นระยะ

## หมายเหตุ

โปรเจกต์นี้จัดทำเพื่อช่วยค้นหาและสุ่มร้านอาหารเท่านั้น ไม่ใช่เว็บไซต์ทางการของ ICONSIAM, ICS หรือร้านค้าที่ปรากฏในรายการ เครื่องหมายการค้าและรูปภาพเป็นของเจ้าของแต่ละราย
